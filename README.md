# 외딴 섬

무인도에서 실시간으로 살며 섬을 넓히고 꾸미는 도트 시뮬레이터 (만드는 중). 원하면 언젠가 섬을 탈출한다.

- 나무 옆에 서면 저절로 도끼질. 통나무로 모닥불 · 닭장 · 집 · 뗏목을 짓는다
- 닭이 낳은 달걀과 낚은 물고기를 모닥불에 구워 먹는다. 닭을 구석으로 몰면 잡을 수도 있다 (대신 달걀이 준다)
- 일을 하면 체력이 줄고, 쉬면 찬다. 배가 비면 체력이 줄고 느려진다. 체력이 0 이면 기절해서 집 앞에서 깨어난다
- 가방은 50칸 (한 칸에 99개). 꽉 차면 못 줍는다. 가방에서 골라 먹고 버린다
- 집이 있으면 뗏목을 엮을 수 있다. 바다에서 먹을 구운 생선을 챙겨 떠난다. 엔딩 카드는 이미지로 저장할 수 있다

## 조작

| | 폰 | PC |
|---|---|---|
| 이동 | 화면을 누른 채 끌기 | 방향키 / WASD |
| 낚시 당기기 | 찌가 쏙 들어갈 때 톡 | 스페이스 / 엔터 |

진행은 브라우저에 저장된다 (localStorage). 오른쪽 위 "처음부터" 로 지운다.

## 실행

빌드 없음. `index.html` 을 브라우저로 열면 된다.

```
python dev/serve.py          # http://127.0.0.1:3240/index.html
```

`index.html?check` 로 열면 `dev/check.js` 확인 시나리오(나무 베기부터 엔딩까지)가 돌고 결과가 화면에 나온다.
저장은 확인용 키에 따로 해서 실제 진행은 건드리지 않는다.
`dev/play.js` 는 방향키 · 버튼만 쓰는 봇이다. 실제 속도로 한 판을 끝까지 돌려 걸린 시간을 잰다 (파일 머리 주석 참고).

## 구조

외부 에셋 없음. 그림은 전부 코드로 찍은 도트(`js/sprites.js`).
숫자(속도 · 시간 · 비용)는 `js/data.js` 한 곳에 있다. 스크립트 읽는 순서는 `index.html` 의 `<script>` 순서.
